1. В бота можно ввести название любого фильма. По кнопке выбрать его жанр -> он добавляется в свою подборку
2. В любой момент можно зайти в свою подборку и получить случайный фильм / выбрать желаемый жанр и увидеть список того, что ты хотел посмотреть
3. Также есть местная база фильмов (популярные культовые)
4. По аналогии можно получить случайный фильм из базы / случайный фильм из базы с фильтром по жанру / увидеть список фильмов из базы по фильтру (желаемому жанру)
5. После просмотра фильма можно поставить оценку и оставить комментарий

на перспективу :
- поиск фильма по части названия (нейронка?)
- добавление в друзья -> просмотр подборок друзей ; совместные подборки (совпадения из своих подборок 2+ людей) ; оценки друзей на фильмы из базы и любой подборки
